# R3 security exceptions

No exceptions approved. Open findings are recorded in `verification.md` and the PR; the images must not be deployed while an actionable finding lacks a fix or PO-approved exception.

An exception must identify the CVE/rule, package/version, runtime/tools target, reachability or reason no fix is possible, mitigation, review trigger and explicit PO confirmation. Secrets cannot be excepted (R3 §3.5).

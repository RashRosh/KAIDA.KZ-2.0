Единый редактор карточки

Один набор компонентов для AI-черновика, пустой ручной формы, правки опубликованной карточки и восстановления из архива. Порядок секций: медиа → название → цена и «Цена за» → условная фасовка → комментарий → торговые точки → действие. Блокирует отправку только отсутствие обязательных данных: название, минимум 1 фото, цена, «Цена за», минимум 1 точка.

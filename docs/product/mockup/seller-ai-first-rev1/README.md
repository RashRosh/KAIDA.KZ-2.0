## Что внутри

- `canvas.json` — список артбордов, страниц и их порядок;
- `*.dc.html` — по файлу на артборд (`S*` — продавец, `OFF*` — режим «ИИ выключен», `B*` — покупатель, `M*` —
  оператор/модератор, `F*` — flows, `P*` — интерактивные прототипы, `States*`, `Motion` — состояния и анимации,
  `Main` — обложка, `Gaps` — открытые вопросы дизайнера);
- `kaida.css`, `ds/kaida/tokens.json` — стили и токены, на которых собран макет.

Файлы открываются только внутри редактора макета (нужны его `support.js` и загруженные иконки `/_blob/…`); здесь они
хранятся как текстовый источник: тексты, состояния, порядок элементов.

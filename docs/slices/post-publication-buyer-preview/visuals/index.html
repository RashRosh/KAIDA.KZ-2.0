Просмотр как у покупателя после публикации — макет для утверждения (не приложение)

Статический прототип на настоящих стилях и шрифтах приложения (Roboto, Geologica). Просмотр открывает настоящую страницу предложения покупателя; отдельного «макета просмотра» нет. Значок глаза — предлагаемый ассет (в проекте есть только «глаз зачёркнутый»): на макете он нарисован из тех же контуров, что и существующий значок, без зачёркивания.

A · Кабинет продавца: страница карточки (одна точка, на витрине). Новый пункт «Как видят покупатели» — оформлен как «Редактировать» и «Выключить»

B · Сразу после публикации: подсвеченная строка витрины получает ссылку (для карточки в нескольких точках она ведёт на страницу карточки с точками)

C · Карточка в нескольких точках: у каждой видимой точки своя ссылка; у выключенной (или скрытой по актуальности) ссылки нет, видно причину

D · Настоящая страница предложения покупателя; сверху одна строка режима просмотра и возврат. Кнопки избранного в просмотре нет (решение PO)

E · Если карточка успела стать недоступной (выключена, скрыта по актуальности, снята оператором): обычная страница «недоступно» покупателя, но с возвратом к карточке

F · 320 px и крупный шрифт (страница карточки продавца и строка режима просмотра)

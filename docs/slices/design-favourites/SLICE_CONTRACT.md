## User task и scope

Покупатель открывает свой список сохранённых предложений: видит цену, точку, продавца и давность подтверждения, открывает предложение, убирает запись; гость видит приглашение войти; пустой список объясняет, как сохранить. Authority — два Artifact в [baseline](../../product/DESIGN_BASELINE.md); доски B09-Fav1 (ST01 гость, ST03 пусто, ST04/ST07 список) и B09-Fav2 (ST02 загрузка, ST05 ошибка списка и ошибка удаления, B10 недоступные записи). Модули: buyer presentation (`FavouritesView`), строки i18n.

Переносится: шапка «Избранное» Geologica 26/32 без стрелки, счётчик записей справа; нижняя навигация из D2 (4 пункта, «Избранное» активно); карточка записи `card res` (фото 88, название 17/24, цена 18/22 с единицей, точка 14/20, продавец 13/18, внизу плашка давности по шкале D2 и ссылка «Убрать из избранного»); недоступная запись на фоне sunken: «Сейчас недоступно», название, «продавец · точка», без цены, адреса и контактов, только «Убрать из избранного»; гость — иллюстрация, «Войдите, чтобы открыть избранное», текст, «Войти», ссылка «Найти товар»; пусто — иллюстрация, «В избранном пока пусто», текст, «Найти товар»; загрузка — три скелетона; ошибка списка — красная плашка с «Повторить»; ошибка удаления — под карточкой «Не удалось убрать из избранного. Запись осталась в списке.» и «Убрать ещё раз».

## Explicit out of scope

Данных для части макета в продукте нет, они не добавляются: «Цена изменилась: было … стало …» (B09.ST06), причины недоступности «срок истёк» / «выключено продавцом» (B10.ST01–02), «Снова доступно» (B10.ST03) — запись просто снова показывается доступной, расстояние «1,2 км» (у списка нет местоположения покупателя). Новых API, миграций, хранения данных о прошлой цене нет. Гостевой вход остаётся существующим окном входа (AuthModal). Страница «Ещё», Рядом и кабинет продавца не мигрируются.

## Пересмотр визуальных ограничений и закрытые contracts

- «Избранное» становится разделом нижней навигации (пункт уже есть в навигации D2), стрелка «назад в Ещё» убирается; ссылка на Избранное в «Ещё» остаётся.
- Ошибка загрузки: в макете «Показаны сохранённые данные», но список в браузере не хранится (приватность, offer-favourites contract), поэтому текст честный: «Не удалось загрузить избранное.» без сохранённых записей.
- В карточке записи по B09 нет маршрута, контактов и строки режима работы (как и в выдаче D2 по решению PO): они на странице предложения, куда ведёт карточка.
- Удаление, порядок, приватность, восстановление позиции прокрутки, возврат со страницы предложения (`return=/favourites`) и поведение при смене сессии — без изменений (`useFavourites`).

5. Нет горизонтального overflow на 320/360/390/768/1440, 200 % текста; reduced motion без масштабирования.

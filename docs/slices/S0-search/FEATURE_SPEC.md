# S0 — First Search Feature Spec

## Пользовательская задача

П1 хочет узнать, где сейчас купить баранину.

Он открывает KAIDA.KZ, вводит `баранина`, получает заранее подготовленное актуальное предложение и видит минимум информации, достаточной для понимания, что товар существует и где его искать.

## Scope

В S0 входят:

- одна страница поиска;
- строка поиска;
- сущности Product, Seller, Location, Offer;
- PostgreSQL;
- API поиска;
- заранее созданные тестовые данные;
- поиск по точному названию товара без учёта регистра;
- карточка результата;
- состояние «ничего не найдено»;
- базовые backend/unit/integration tests;
- E2E-сценарий через реальный интерфейс;
- mobile и desktop проверка.

Карточка результата содержит минимум:

- Product;
- цену, если она указана;
- Seller;
- Location;
- seller comment, если он указан.

Цена необязательна на уровне модели.

## Out of scope

Специально не входят:

- регистрация;
- авторизация;
- кабинет продавца;
- создание/редактирование Offer через UI;
- Seller Change Set;
- Category;
- synonyms/aliases;
- AI;
- геолокация покупателя;
- расстояния;
- карты;
- фильтры;
- рекомендации;
- рейтинги;
- отзывы;
- изображения;
- контакты;
- Telegram;
- аналитика;
- монетизация;
- admin panel;
- инфраструктура будущих slices.

## Acceptance criteria

S0 готов только если одновременно выполняется всё следующее:

1. Чистая локальная установка проекта поднимается по документированной инструкции.
2. В БД можно загрузить тестовые данные штатной командой.
3. В seed существует Offer для `Баранина`.
4. Пользователь открывает KAIDA.KZ.
5. Вводит `баранина`.
6. Запускает поиск.
7. Получает правильный Offer.
8. Вводит `говядина` и видит Offer без цены с текстом `Цена не указана`.
9. Вводит `единорог` и получает empty state.
10. Пустой запрос корректно валидируется.
11. UI работает на mobile и desktop.
12. Автоматические тесты проходят.
13. E2E воспроизводит сценарий через браузер.
14. Production build проходит.
15. Функция вручную пройдена как пользователь.
16. После проверки рабочая версия зафиксирована в Git.

## Definition of user value

После S0 KAIDA.KZ уже умеет одну реальную вещь:

> найти в PostgreSQL тестовое предложение конкретного товара и показать его человеку через рабочий веб-интерфейс.

S0 не считается доказательством готовности остальных функций KAIDA.KZ.

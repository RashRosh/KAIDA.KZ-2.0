Автоматическое исправление опечатки — макет для утверждения (не приложение)

Статический прототип на настоящих стилях и шрифтах приложения (Roboto, Geologica). Сначала выполняется исходный поиск; только если он вернул ноль и есть одно уверенное исправление, показываются результаты исправленного запроса с объяснением и возвратом к вводу.

0 · Сейчас (принято, v0.0.69): запрос с опечаткой без совпадений — нулевой результат с общим советом

A · Предложение: исходный поиск вернул ноль, найдено одно уверенное исправление — показаны его результаты. Поле остаётся как набрано; над результатами две строки текста: что показано (исправленный запрос выделен) и ссылка «Искать вместо этого»

B · Несколько слов: исправляются неизвестные слова, известные остаются как набраны

C · «Искать как введено»: исходный текст без исправления — обычный нулевой результат (без блока и без подсказок)

D · Когда исправления нет (экран как сейчас): ничья между разными словами, нет близкого слова, слово не из каталога («машина»), замена согласной у короткого слова, все слова известны, исправленный запрос без предложений, запрос уже даёт карточки

E · Казахский интерфейс (те же русские слова: поиск не зависит от языка интерфейса)

F · 320 px и крупный шрифт (блок и кнопка растут, не обрезаются)

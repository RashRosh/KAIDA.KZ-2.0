## Поправки к исходной карте
+
- **P1-02.2.** Выбранный Product добавляет кандидатов. Закрытый S15B-4a сохраняет совпадения по словам и считает ноль по общему пулу. Карта уточнена по контракту.
+- **P1-07.1, P2-03.3.** Публичный Telegram по handle уже есть. Привязка стабильным ID через бота, Telegram поддержки и канал ввода продавца имеют разные основания.
+- **P2-15.1–.3.** Возврат из архива актуальности уже работает. Автоудаление не входит в действующий контракт актуальности. Будущий срок хранения и удаление требуют отдельного решения.

# Do not regress

- Название карточки — свободное, смешанный ввод с подсказками каталога (контракт §8, решения a–g).
- Цена > 0; «Другое» — одно слово 1–20 букв; черновики только для новых карточек.
- Правка одной точки многоточечной карточки меняет только цену (`CardSharedFieldsError`, HTTP 409).
- Каждая публикация/правка идёт через `SellerChangeSet` и экран подтверждения с текстом ответственности.
- Снятие оператором — одно правило видимости для всех путей покупателя; не дублировать его по экранам.
- Разметка продавца = классы макета; `kaida.css` не править вручную (пере-генерировать из макета).
